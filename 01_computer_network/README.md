# Computer Networks

[Home](../README.md)

**Objective:** Explain how applications communicate, packets reach their destination, and reliability and security are provided.

## Reading order

1. [Foundations and layers](01_foundations_and_layers.md)
2. [Addressing and routing](02_addressing_and_routing.md)
3. [Transport protocols](03_transport_protocols.md)
4. [Web protocols and security](04_web_protocols_and_security.md)
5. [Interview practice](05_interview_practice.md)

Prioritize OSI/TCP-IP, subnetting, DNS/ARP, TCP/UDP, the three-way handshake, flow/congestion control, HTTP/HTTPS, and “what happens when you enter a URL?”

**Mental model:** An application writes to a socket. Transport identifies application endpoints; IP routes across networks; link protocols deliver frames on individual hops. Link delivery and transport receipt do not prove successful application processing.
