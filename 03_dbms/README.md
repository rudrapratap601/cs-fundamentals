**Objective:** Model data, write correct SQL, reason about concurrent transactions, and explain query performance.

## Reading order

1. [Relational modeling and normalization](01_modeling_and_normalization.md)
2. [SQL and query patterns](02_sql_and_query_patterns.md)
3. [Transactions and concurrency](03_transactions_and_concurrency.md)
4. [Indexes, storage, and scaling](04_indexes_storage_scaling.md)
5. [Interview practice](05_interview_practice.md)

Prioritize keys, joins, NULL, normalization, ACID, isolation levels, indexes, and SQL exercises. Always state assumptions about duplicates, ties, missing rows, and the database engine.

**Mental model:** A database combines a data model and query language with integrity rules, concurrency control, physical storage, and recovery. A query's logical result is different from its physical execution plan.
