# Object-Oriented Programming

[Home](../README.md)

**Objective:** Explain object-oriented concepts and use them to design code that is understandable, testable, and adaptable.

## Reading order

1. [Objects and the four pillars](01_objects_and_four_pillars.md)
2. [Polymorphism and language behavior](02_polymorphism_and_language_behavior.md)
3. [SOLID and object relationships](03_solid_and_relationships.md)
4. [Patterns and design exercises](04_patterns_and_design_exercises.md)
5. [Interview practice](05_interview_practice.md)

Examples use Java unless explicitly labeled otherwise. Most ideas transfer to other languages, but dispatch, inheritance, memory management, access rules, and copying do not behave identically everywhere.

Prioritize the four pillars, overloading/overriding, interfaces/abstract classes, composition, SOLID, equality, and a small design exercise.

**Mental model:** Objects combine state with behavior and expose contracts. Good design keeps invariants inside the objects responsible for them and lets callers depend on stable capabilities instead of internal details.
